# Piano Strategico Ribrain 2026–2027

Documento strategico interno per Ribrain Studio. Confidenziale soci.

## Struttura

- **`index.html`** → M0 Executive Summary (entry point)
- **`m5.html`** → M5 Calendario commerciale · deep-dive interattivo
- **`m6.html`** → M6 Economics & proiezioni · 3 configuratori + scenari 18 mesi

## Pubblicazione su GitHub Pages

1. Carica i 3 file HTML nella root del repository
2. Settings → Pages → Source: Deploy from branch · `main` · `/ (root)`
3. Il sito sarà disponibile a `https://<username>.github.io/<repo-name>/`

## Note

I file usano solo CDN esterni (Google Fonts, GSAP, Chart.js). Nessun build necessario, nessuna dipendenza locale. Funzionano anche aprendoli direttamente da filesystem (`file://`).

I link tra le pagine sono relativi: M5 → `index.html` (M0), M5 → `m6.html`, ecc. Per funzionare correttamente i 3 file devono stare nella **stessa cartella**.
